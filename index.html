雙人合作推理

懷錶檔案

兩人・各用一支手機・序章＋三個案件

怎麼玩

  1. 兩個人各用自己的手機打開這個網頁，一起選同一章，一人當「現場調查員」，一人當「偵訊官」。
  2. 不能看對方的畫面，只能用說的。
  3. 從第一章起，每件證物都有編號。偵訊官可以在嫌疑人面前「出示證物」，逼出新的口供；現場有些鎖，要靠口供裡的線索才打得開。
  4. 討論好了，一起打開「提出指控」。破案後會拿到下一章的通行碼，兩支手機都要輸入。

這個網址沒辦法解鎖章節：瀏覽器只在 https 網址或本機（localhost）開放解密功能。請改用 GitHub Pages 的 https 網址。
